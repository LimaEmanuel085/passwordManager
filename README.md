# API de criptografia de senhas
Esta é uma API de criptografia de senhas feita com Python, tanto com Flask quanto com Django REST Framework.<br>
A API não possui integração com banco de dados e faz uso de Bcrypt para fazer o hash das senhas.<br>
Isso significa, em outras palavras, que as senhas não ficam armazenadas em nenhum local.

## Status:
API finalizada e funcionando.

## Pré-requisitos:
Python 3.13<br>
Ambiente virtual (recomendado)<br>
Bibliotecas (para baixá-las, pip install -r requirements.txt)

## Sobre a API:
Este repositório possui duas pastas principais: "api_drf" e "api_flask".<br>
A pasta "api_drf" contém a API feita num modelo de projeto Django, com o uso do Django REST Framework.<br>
A pasta "api_flask" contém a API feita num modelo de projeto Flask.
